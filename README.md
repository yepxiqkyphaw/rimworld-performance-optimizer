## Overview

Performance Optimizer patches RimWorld's most expensive tick loops with adaptive throttling, caching, and parallel processing, delivering 30–200% FPS gains on late-game colonies without changing gameplay.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RimWorld Performance Optimizer** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Adaptive Throttling** | Reduces update frequency for off-screen and idle pawns automatically |
| **Path Cache** | Caches recently computed pathfinding results to skip redundant searches |
| **Parallel Ticks** | Distributes independent pawn ticks across CPU threads safely |
| **FPS Graph** | In-game overlay showing per-system tick cost for profiling |
